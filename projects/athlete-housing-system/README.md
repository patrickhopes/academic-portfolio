# Athlete Housing Search and Approval System

This systems analysis and design project specifies a housing search and residence approval workflow for university athletes and athletic department staff. It connects requirements to interface screens, data flows, and relational data structures.

## Deliverable

[report.pdf](report.pdf) is the original 84-page design submission. It contains the requirements, screen inventory and prototype captures, context and lower-level data flow diagrams, process descriptions, ERD, data tables, activity diagrams, and Mermaid source appendix.

## Design scope

The report lists 12 requirements and documents a 20-screen prototype. Athlete workflows cover login, profile and budget management, residence search, submission, and status tracking. Staff and administrator workflows cover review, roles, approved sources, and system history.

The prototype URL recorded in the report is [is4430gp.netlify.app](https://is4430gp.netlify.app/). Its current availability could not be independently verified while preparing the portfolio. The PDF contains screenshots for review if the prototype is unavailable.

This is a requirements and design submission with a clickable prototype. It does not establish a production implementation of authentication, university integrations, or automated data collection. The prototype source repository was not supplied in this collection.
