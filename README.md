# Patrick Hopes | Academic Project Portfolio

This portfolio brings together seven academic projects that connect business questions with technical work in data analytics, information systems, database design, and AI evaluation. Each case study explains the problem, methods, deliverables, and reported findings, with the source files and supporting reports available alongside it.

The site is a responsive, accessible static page built with HTML, CSS, and JavaScript. Its styling, project filters, configuration, and source figures are embedded in `index.html`; downloadable project files live in the `projects` folder.

## Open the portfolio

Open [index.html](index.html) in a browser, keeping it beside the `projects` folder. Once GitHub Pages is enabled, use the published `github.io` website URL. The HTML page uses relative paths so it works at both a user site and a repository-based project site.

## Publish and customize

Follow [the setup guide](GITHUB-SETUP-GUIDE.md), or open [the formatted guide](GITHUB-SETUP-GUIDE.html) in a browser. It covers account and repository setup, uploading all documents, selecting `main` and `/(root)` for Pages, testing links, and updating the site.

The `PORTFOLIO` settings near the top of `index.html` control the displayed name, initials, GitHub account, LinkedIn URL, optional public contact email, and optional individual contribution statements. No backend or API key is required.

## Attribution and project scope

Group projects are identified as collaborative submissions. Original author credits are retained in the source files and project notes, including the Patrick Hopes or Patric Hopes names appearing in several documents. Confirm the display name and attribution before publishing.

All ten supplied attachments are preserved byte-for-byte under simplified filenames. Performance values are reported from those artifacts and were not independently reproduced for this portfolio. Missing source datasets, model scripts, and optional visualization dependencies are documented in the relevant project notes. The loan workbook is an academic demonstration rather than a validated lending model.

Some original materials contain third-party content and group contributions; no blanket license has been added to the collection. Add a license only after determining the rights for the material you intend to license.
